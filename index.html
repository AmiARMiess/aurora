Workflow

Three steps. Zero boilerplate.

  1. 01

    Install the core

    One dependency, no bundler gymnastics. It also runs straight from a CDN if you prefer.

  2. 02

    Describe your scene

    Declare objects, materials and lights with plain objects — the graph builds itself.

  3. 03

    Ship at 60 fps

    Aurora frustum-culls, pools and batches for you, then hands back the bytes you saved.

aurora.config.js 
import { Scene } from 'aurora';

const scene = new Scene();
scene.add({
  geometry: 'sphere',
  material: 'iridescent',
  motion:   'orbit'
});

scene.render({ fps: 60 });
